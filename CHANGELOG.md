# История изменений

Все значимые изменения проекта документируются в этом файле.
Формат основан на Keep a Changelog, версионирование — Semantic Versioning.

## [0.2.0] - 2026-11-15

### Добавлено
- Новый модуль `MarkdownReport` — генерация отчёта в формате Markdown
- Модульные тесты xUnit для `ReportService`
- CI-пайплайн GitHub Actions (сборка и тесты)

## [0.1.0] - 2026-11-15

### Добавлено
- Инициализация проекта: система генерации отчётов на C# (.NET 8)
- Интерфейс `IReportGenerator` и реализации PDF, Excel, HTML, CSV
- Функция логирования в консоль и файл `logs/app.log`
- Разрешение конфликта в `README.md`
- Публикация репозитория на GitHub
